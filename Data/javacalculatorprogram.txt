### Java Calculator – A Simple Console Application

```java
// -------------------------------------------------------------
//  SimpleCalculator.java
//  A basic command‑line calculator that supports +, -, *, /
// -------------------------------------------------------------
import java.util.Scanner;

public class SimpleCalculator {

    // Performs the calculation based on the operator
    private static double calculate(double a, double b, char op) {
        return switch (op) {
            case '+' -> a + b;
            case '-' -> a - b;
            case '*' -> a * b;
            case '/' -> {
                if (b == 0) {
                    throw new ArithmeticException("Cannot divide by zero");
                }
                yield a / b;
            }
            default -> throw new IllegalArgumentException("Unsupported operator: " + op);
        };
    }

    public static void main(String[] args) {
        System.out.println("=== Welcome to the Simple Java Calculator ===");
        try (Scanner scanner = new Scanner(System.in)) {

            System.out.print("Enter first number: ");
            double num1 = scanner.nextDouble();

            System.out.print("Enter an operator (+, -, *, /): ");
            char operator = scanner.next().charAt(0);

            System.out.print("Enter second number: ");
            double num2 = scanner.nextDouble();

            double result = calculate(num1, num2, operator);
            System.out.printf("Result: %.4f%n", result);
        } catch (ArithmeticException ae) {
            System.err.println("Error: " + ae.getMessage());
        } catch (Exception e) {
            System.err.println("Invalid input. Please enter numeric values and a valid operator.");
        }
    }
}
```

#### How It Works
1. **Input** – The program prompts the user for two numbers and an operator.  
2. **Processing** – The `calculate` method uses a *switch expression* (Java 17+ syntax) to perform the desired operation.  
3. **Error Handling** –  
   * Division by zero throws an `ArithmeticException`.  
   * Any unsupported operator throws an `IllegalArgumentException`.  
   * Non‑numeric input is caught by the generic `Exception` block and reported to the user.  
4. **Output** – The result is printed to four decimal places for clarity.
